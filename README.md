# kladde-dev.github.io

The published documentation of kladde, at <https://kladde-dev.github.io/>.

Nothing here is edited by hand.
The workflow of [kladde-docs](https://github.com/kladde-dev/kladde-docs) builds the site and the PDF from that repository's `main`, and pushes the result to this repository's `gh-pages` branch, which GitHub Pages serves; it has to be this repository, since only one of this name serves the organization's root URL.
See "Deployment" in kladde-docs' README for the one-time setup.
